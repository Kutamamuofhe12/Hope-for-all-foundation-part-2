# Hope For All Foundation

## Part 2 – CSS Styling and Responsive Design
- Created and linked the external `css/style.css` stylesheet to the HTML pages.
- Added a CSS reset and consistent base styles for typography, spacing and colours.
- Added Flexbox and CSS Grid layout rules for desktop content.
- Added decorative styling including backgrounds, borders, shadows and buttons.
- Added `:hover`, `:focus-visible` and `:active` pseudo-classes for interactive elements.
- Added tablet and mobile breakpoints using media queries.
- Added responsive typography using relative units and `clamp()`.
- Added responsive image rules using `max-width: 100%` and `height: auto`.
- Added the viewport meta tag to support responsive layouts.
